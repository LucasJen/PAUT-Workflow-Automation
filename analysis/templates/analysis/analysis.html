Edited

Open a file to see its gates.

Type: Sound path - the same stretch of time on every beam (an arc on a sectorial scan); True depth - between two depths on every beam; Box - inside a box of depth and index; beams that miss it have no gate (grey on the C-scan) or, if you choose, zero amplitude (white). Depth and box gates start from the pulse. Gates you add can be removed (bin icon).

On the S-scan drag a gate's edges to change its start or end (a box: any side) and its letter tab to move it. On the A-scan drag a gate's bar (up / down changes its threshold) and its end ticks.
